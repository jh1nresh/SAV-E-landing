# SAV-E landing

Hero-only Next landing page for the SAV-E public TestFlight beta.

## Config

Set the public TestFlight invite URL when deploying:

```bash
NEXT_PUBLIC_TESTFLIGHT_URL="https://testflight.apple.com/join/..."
```

## Run

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.

## Build

```bash
npm run build
```
